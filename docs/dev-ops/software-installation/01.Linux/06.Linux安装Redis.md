::: tip 环境说明及准备工作

- 操作系统：Rocky 10
- Redis版本：Redis 7.2.16

```bash
# 下载源码包
cd /data/downloads
wget https://github.com/redis/redis/archive/refs/tags/7.2.16.tar.gz

# 安装编译环境
dnf install gcc make

# 如果需要远程访问，需要开放 6379 端口，云服务器还需控制台配置安全组访问。
firewall-cmd --add-port=6379/tcp --permanent
firewall-cmd --reload
```

:::

## 1. 安装及配置Redis

```bash
# 解压
tar -zxvf 7.2.16.tar.gz

# 编译Redis
cd redis-7.2.16
make

# 在`/data/soft`下创建多个文件夹
mkdir -p /data/soft/redis/{etc,data}

# 安装Redis, 将Redis安装在/data/soft/redis目录下
make PREFIX=/data/soft/redis install

# 复制redis.conf配置文件到/data/soft/redis/etc目录下
cp redis.conf /data/soft/redis/etc

# 添加环境变量, 任何目录下都可以使用redis-server、redis-cli等等
vi ~/.bashrc
# 最后面添加
export PATH=$PATH:/data/soft/redis/bin

# wq保存修改后刷新文件
source ~/.bashrc
```

修改配置文件

```bash
# 打开配置文件
vi /data/soft/redis/etc/redis.conf

# 修改后台启动, 默认为daemonize no, 修改为daemonize yes
daemonize yes

# 客户端闲置多长时间后断开连接, 默认为0关闭此功能
timeout 0

# 设置密码, 默认被注释, 取消注释修改为自定义密码(我的是123456)
requirepass 123456

# 监听ip, 允许访问的ip, 默认为127.0.0.1, 修改为0.0.0.0(允许所有服务器ip访问)或者注释掉
bind 0.0.0.0

# 指定监听端口, 默认为6379, 此处我保持默认
port 6379

# 是否开启AOF持久化，默认为no
appendonly yes

# 修改AOF及RBD存放路径, 默认为./, 修改为/data/soft/redis/data
dir /data/soft/redis/data

# 修改log存放路径, 默认为"", 修改为"/data/soft/redis/data/redis_6379.log"
logfile "/data/soft/redis/data/redis_6379.log"
```

启动Redis，这里碰了个坑，开始没指定配置文件启动，然后远程连接不上。

```bash
# 启动
redis-server /data/soft/redis/etc/redis.conf

# 查看Redis是否启动
ps -ef | grep redis

# 本地命令连接redis
redis-cli
# 输入配置密码即可
auth 123456

# 远程则自行使用工具查看
```

## 2. 开机自启

这时候 Redis 每次重启还不能自动启动，需要把他设置为自启。

添加文件：

```bash
# 新建文件
vi /etc/systemd/system/redis.service

# 添加内容
[Unit]
Description=redis.server
After=network.target

[Service]
Type=forking
PIDFILE=/var/run/redis_6379.pid
ExecStart=/data/soft/redis/bin/redis-server /data/soft/redis/etc/redis.conf
ExecReload=/bin/kill -s HUP $MAINPID
ExecStop=/bin/kill -s QUIT $MAINPID
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

保存文件之后，可以使用systemctl来管理了，使用 `systemctl enable redis.service` 开启自动重启，然后重启查看效果。

```bash
# 启动redis服务
systemctl start redis.service

# 停止redis服务
systemctl stop redis.service

# 重启redis服务
systemctl restart redis.service

# 查看redis服务当前状态
systemctl status redis.service

# 设置redis服务开机自启动
systemctl enable redis.service

# 停止redis服务开机自启动
systemctl disable redis.service
```

## 安装脚本

```bash
#!/bin/bash
# Linux 安装 Redis 7.2.16（适用于 Rocky 10 等 dnf 系统）
set -e

REDIS_VERSION="7.2.16"
DOWNLOAD_DIR="/data/downloads"
INSTALL_DIR="/data/soft/redis"
PASSWORD="123456"

# 1. 下载源码包
mkdir -p "$DOWNLOAD_DIR"
cd "$DOWNLOAD_DIR"
wget "https://github.com/redis/redis/archive/refs/tags/${REDIS_VERSION}.tar.gz"

# 2. 安装编译环境
dnf install -y gcc make

# 3. 开放 6379 端口（云服务器还需在控制台配置安全组）
firewall-cmd --add-port=6379/tcp --permanent
firewall-cmd --reload

# 4. 解压并编译
tar -zxvf "${REDIS_VERSION}.tar.gz"
cd "redis-${REDIS_VERSION}"
make

# 5. 安装到 /data/soft/redis
mkdir -p "$INSTALL_DIR"/{etc,data}
make PREFIX="$INSTALL_DIR" install
cp redis.conf "$INSTALL_DIR/etc/"

# 6. 添加环境变量
grep -q "$INSTALL_DIR/bin" ~/.bashrc || echo "export PATH=\$PATH:$INSTALL_DIR/bin" >> ~/.bashrc

# 7. 修改配置文件
CONF="$INSTALL_DIR/etc/redis.conf"
sed -i \
  -e 's/^daemonize no/daemonize yes/' \
  -e 's/^timeout 0/timeout 0/' \
  -e "s/^# requirepass foobared/requirepass ${PASSWORD}/" \
  -e 's/^bind 127.0.0.1 -::1/bind 0.0.0.0/' \
  -e 's/^bind 127.0.0.1/bind 0.0.0.0/' \
  -e 's/^appendonly no/appendonly yes/' \
  -e "s|^dir ./|dir ${INSTALL_DIR}/data|" \
  -e "s|^logfile \"\"|logfile \"${INSTALL_DIR}/data/redis_6379.log\"|" \
  "$CONF"

# 8. 配置 systemd 开机自启
cat > /etc/systemd/system/redis.service <<EOF
[Unit]
Description=redis.server
After=network.target

[Service]
Type=forking
PIDFILE=/var/run/redis_6379.pid
ExecStart=${INSTALL_DIR}/bin/redis-server ${INSTALL_DIR}/etc/redis.conf
ExecReload=/bin/kill -s HUP \$MAINPID
ExecStop=/bin/kill -s QUIT \$MAINPID
PrivateTmp=true

[Install]
WantedBy=multi-user.target
EOF

# 9. 启动并设置开机自启
systemctl daemon-reload
systemctl enable --now redis.service
systemctl status redis.service
```
